Set up founder MFA

Scan this live Odyssey QR code with your authenticator (a phone app, a browser extension like Bitwarden or 1Password, or a hardware security key manager). It will then generate a new 6-digit code every time period for founder sign-in.

Creating a new secure TOTP QR code…
  1. Open your TOTP authenticator (app, browser extension, or password manager).
  2. Choose Add account or Scan QR code.
  3. Scan the QR code shown on this Odyssey page, or use the manual setup key below if you can't scan it.
  4. Your authenticator will show a rotating 6-digit code.
  5. Enter that code below to activate MFA.
Treat the QR code and setup key like a password. Only scan it with the authenticator you trust. Odyssey does not need you to send the secret to another website. This QR is shown once, for this enrollment only — it will not be shown again after you verify.
